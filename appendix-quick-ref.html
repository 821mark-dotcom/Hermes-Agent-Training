The RCTF Prompt Framework

Role

"Act as a senior Python engineer…" — sets expertise level and perspective.

Context

"This project fetches from Jira and publishes to Confluence…" — grounds the answer.

Task

"…refactor the error handling in jira_client.py…" — specific, actionable.

Format

"…return a diff, a one-line summary, and risk level." — controls output shape.

Full RCTF example
Do this
Use this prompt in the appropriate chat, terminal, or field.
Paste into chat
Role: Act as a senior Python developer with REST API expertise. Context: This project fetches Jira sprint data and publishes formatted reports to Confluence. Auth uses API tokens from environment variables. Task: Refactor the authentication flow in jira_client.py to handle token expiry gracefully without crashing. Format: Show the change as a diff, a one-sentence summary of what changed, and a yes/no on whether existing tests need updating.

Prompt Patterns

❌ Weak

Fix the bug

No file, no function, no expected behavior — Hermes will guess.

✅ Strong

In jira_client.py, get_sprint_issues() returns empty list when sprint has issues. Read the function, identify the cause, fix it. Show me the diff.

❌ Weak

Make it faster

No measurement baseline, no context — can't produce a useful answer.

✅ Strong

The API call in generate_report() takes 8 seconds. Profile it, find the bottleneck, and suggest 2 optimizations with estimated time savings.

Recovery Toolkit

Hallucination

Agent states something confidently that's wrong.
Fix: "Show me the exact line in the file that confirms this."

Wrong Edit

Fix: git diff to see changes, git checkout -- filename to undo.

Stuck / Looping

Fix: "Stop. Forget that approach. Instead, try [new strategy]. Start from step 1."

Bad Conversation

Fix: Start a new chat. Old context may be biasing all responses — fresh start is faster.
