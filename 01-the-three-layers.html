Section 01

The Three Layers — How It All Fits Together

⏱ 8 minBeginnerIntermediateAdvanced
ELI10

Three floors of a building. Floor 1: VS Code + Copilot — where most developers already live. Floor 2: Hermes Agent adds a persistent brain that remembers, runs on a schedule, and answers from your phone. It is the agent runtime, not the visual task board. Floor 3: Hermes Workspace gives that brain a visual command center with Kanban, jobs, swarm, and orchestration tools. You can stop at any floor. Move up when you're ready.

ℹ️All three layers are independent and concurrent. Use Layer 1 alone — it works perfectly. Add Layer 2 when you want persistence, scheduling, or mobile access via the Hermes Agent runtime and web UI. Add Layer 3 when you want the full visual command center: Conductor, Operations, Swarm, Kanban, jobs, and live dashboards. Each augments, never replaces, what came before.

What each layer gives you

Layer 1 gives you
  • Inline code completions
  • Chat panel in VS Code
  • File & workspace context
  • Basic agentic edits
  • Prompt templates (.prompt.md)
Layer 2 adds
  • Memory across sessions
  • 2,000+ reusable skills
  • Runs while you're away
  • Telegram / Slack / 20+ platforms
  • Cron-scheduled automations
  • Parallel subagents
  • Own Web UI at :9119
Layer 3 adds
  • Mission orchestration (Conductor)
  • Multi-agent Operations console
  • Swarm + Kanban task board
  • Jobs queue & monitoring
  • Live tool call visualization
  • Memory browser & live editor
  • Cost / session / model dashboard

⚡Start with Layer 1 first. Get one clean conversation working before adding the gateway, workspace, or any other features.
⚡hermes doctor is your first debug step at any layer — it diagnoses config issues, missing keys, and service state in seconds.
⚡Profiles are isolated: each Hermes profile has its own config, sessions, and skills. Use profiles to separate work/personal or different projects.
