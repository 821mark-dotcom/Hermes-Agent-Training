MCP — External Tools and Integrations

⏱ 8 minIntermediateAdvanced
ELI10

MCP (Model Context Protocol) lets Hermes connect to external tools and services: GitHub, databases, file systems, and more, through a standardized protocol. This is separate from the Workspace Dashboard: Dashboard is the operational console; MCP is the extension channel that plugs in new tools.

⚡ Hermes Agent / Workspace — MCP Integration
  • MCP servers — connect any MCP-compatible tool: GitHub, Postgres, Slack, file systems, custom APIs
  • Tool discovery — Hermes automatically discovers tools exposed by connected MCP servers
  • Catalog — browse Nous-approved MCP servers from within the Workspace MCP page
  • Per-server filtering — enable only the tools you want from each server
Terminal — add an MCP server
