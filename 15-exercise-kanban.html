Your First Task Sprint

⏱ 20 minBeginnerIntermediate
🎯 Exercise Goal

Manually create a sprint of tasks, navigate the full Kanban board, experience every column, move cards, and watch the dispatcher pick up an assigned task — all without writing a single prompt to an agent.

ELI10

Before you let agents run loose on a board, you need to know how the board works. This exercise is you driving the car in an empty parking lot: create tasks, drag them around, open the detail drawer, and understand what "Triage → Todo → Ready → In Progress → Review → Done" actually means in practice. Then you'll assign one task to an agent and watch it get picked up automatically.

⚡ Hermes Agent — What You'll Use
  • Dashboard Kanban (localhost:9119/kanban) — the full Kanban board with all columns, drag-drop, and dispatcher controls. Note: Workspace Tasks is a lightweight preview — use the Dashboard for this exercise.
  • Column + buttons — create tasks directly in any column
  • Card drawer — click any card to open the detail panel (assignee, description, dependencies, status actions)
  • Nudge dispatcher — skip the 60s wait and force a dispatch pass now
  • CLI mirror — hermes kanban list shows the same board state in the terminal
📋 Expected Output: 5 tasks created, spanning at least 3 different columns, with 1 task in Done. One task assigned to the default profile and dispatched to In Progress via the Nudge dispatcher button.

Step-by-Step

  1. Open Dashboard Kanban
    Navigate to localhost:9119/kanban. Note the toolbar: Orchestration: Auto pill, Nudge dispatcher button, column count badges all showing 0.
  2. Create your first task in Triage
    Click + on the Triage column header. Title: "Audit current API authentication flow". Leave assignee blank. Click create. The task appears as a card.
  3. Create 4 more tasks across different columns
    Click + on Todo → "Design new auth token schema"
    Click + on Ready → "Implement token refresh endpoint" — set assignee: default
    Click + on Triage → "Write unit tests for token flow"
    Click + on Triage → "Update API documentation"
  4. Open a card and explore the detail drawer
    Click the "Audit current API..." card (not a drag — a click). The drawer opens on the right. Explore: editable title, assignee dropdown, priority badge, description field, dependency editor (add parent/child), status action row (→ ready / → running / block / complete / archive).
  5. Drag a card between columns
    Drag "Audit current API..." from Triage to Ready. Watch the status badge change. The card is now visible in the Ready column with a gray "ready" dot.
  6. Assign the Ready task and nudge the dispatcher
    Click "Implement token refresh endpoint" to open its drawer. Confirm assignee is default and status is Ready. Close the drawer. Click Nudge dispatcher in the toolbar. Within a few seconds the task should move to In Progress — the gateway has spawned the default profile as a worker.
  7. Mark a task Done
    Open the "Design new auth token schema" drawer. In the status action row, click complete. Add a result note: "Schema defined: JWT with 15m access token, 7d refresh token, user_id + scopes payload." The card moves to Done. Note the board header stats update.
  8. Mirror the board in the terminal
    Terminal
    hermes kanban list hermes kanban stats

    The CLI output matches the board exactly — both surfaces read from the same kanban.db.

Real-World Use Case Examples

Sprint Planning

Drop your entire backlog into Triage at once. Manually promote the highest-priority items to Ready. Let the dispatcher pick them up as agent capacity allows.

Code Review Queue

Each PR becomes a task in Triage. The reviewer profile picks up Ready items. Blocked = awaiting author response. Review = LLM finished, waiting for human sign-off.

Onboarding Checklist

Create one task per onboarding step. A human moves them manually as each step completes — no agents needed. The board is the audit trail.

⚡Triage ≠ Todo. Triage is for rough ideas where the spec isn't ready. Todo is for fully specified tasks waiting on a dependency or assignment. Don't use Triage as a permanent parking lot — it triggers the auto-decomposer on every dispatcher tick.
⚡The column + button inherits the column's status. Click + on Ready to create a task that starts Ready (dependencies satisfied, just needs an assignee). Click + on Triage to create a task that starts as a rough idea.
⚡Nudge dispatcher is your fast-forward button. The dispatcher normally runs every 60s. During exercises and testing, use Nudge to skip the wait and see results immediately.
⚡In Progress ≠ Running. The Dashboard column is labelled "In Progress" but the underlying status is running. In the CLI (hermes kanban list), you'll see running — same thing.
