Messaging Gateway — Hermes on 20+ Platforms

⏱ 10 minBeginnerIntermediateAdvanced
ELI10

The Messaging Gateway lets you talk to Hermes from any messaging app — not just the browser UI. Text your agent on Telegram while it runs on a server. Have it send automated reports to your Slack channel. Respond to Hermes questions from your phone. One agent, everywhere you are.

⚡ Hermes Agent — Supported Platforms

📱 Mobile

Telegram · WhatsApp · Signal · SMS

💼 Team

Slack · Microsoft Teams · Discord · Mattermost

📧 Other

Email · Matrix · DingTalk · Feishu · WeCom · Home Assistant · Google Chat

20+ platforms total from one gateway config. One agent responds on all.

Live Setup — Telegram (fastest path)

  1. Start the gateway: hermes gateway run
  2. Run setup wizard: hermes gateway setup — select Telegram
  3. Create a bot via @BotFather on Telegram → get your bot token
  4. Paste the token when prompted
  5. Set your Telegram user ID as an allowed user
  6. Message your bot — Hermes responds

⚡Test in DM first: Before routing to a team channel, test Gateway responses in a private DM to verify output quality.
⚡hermes send for scripts: hermes send --to telegram "deploy finished" works from cron jobs, CI hooks, and monitoring daemons without starting a gateway loop — it talks directly to the platform's REST API.
⚡WSL users: Use hermes gateway run (not start) and wrap in tmux: tmux new -s hermes 'hermes gateway run' for persistence.
