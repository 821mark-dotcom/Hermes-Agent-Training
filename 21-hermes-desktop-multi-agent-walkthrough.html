Hermes Agent Desktop - Multi-Agent Walkthrough

10 minBeginner
ELI10

You give the Hermes Desktop app one goal. The selected Hermes profile acts as the orchestrator, delegates smaller jobs to child agents, watches them finish, and reports the results back in the conversation.

Desktop note: Desktop labels and layout can vary by release. Look for the profile/model controls and the new conversation control; verify the runtime through the evidence below.

1. Open a Desktop conversation

  1. Launch Hermes.app.
  2. Start a new conversation using the app's new-chat or new-session control.
  3. Select the conductor profile, or the profile configured as your orchestrator.
  4. Confirm a model is selected before sending the goal.
Checkpoint

The profile and model controls should show a usable configuration. If the model is blank, fix provider configuration before testing agents.

2. Run the smallest delegation test

Paste into the Desktop conversation
You are the orchestrator. Delegate exactly two child tasks in parallel:
Child A: compute 2+2.
Child B: compute 3*3.
Report each child ID, task, and result.

3. Observe the live evidence

In the Desktop conversation, look for:

  • A visible delegate_task tool or activity event.
  • Two child-agent activities or result entries.
  • Progress such as 1/2 and 2/2.
  • Completed status for both children.
Expected evidence
delegate_task 1/2 - ALPHA Completed
delegate_task 2/2 - BETA Completed

4. Confirm the audit trail

Keep the Desktop conversation open or use its history/session view. The useful audit record is:

  • Original goal
  • Delegation event
  • Child IDs such as sa-0-...
  • Child tasks and returned results
  • Final parent-agent synthesis
Proof standard: A final answer alone is not enough. Confirm that the activity trace shows multiple child agents and completed results.

5. Move to a real goal

Example Desktop goal
Research three approaches for this project, have one child draft an implementation plan,
have another challenge the plan, then synthesize a recommendation. Ask me only the
questions needed to resolve genuine ambiguity. Report child IDs, handoffs, blockers,
and evidence before the final recommendation.

What success means

ObservedMeaning
delegate_taskThe orchestrator delegated instead of doing everything itself.
Two child IDsMultiple agents actually participated.
Completed resultsChild work returned to the parent agent.
Final synthesisThe parent managed the handoff without manual copy/paste.
Scope: This verifies native Hermes multi-agent delegation. It does not require the separate Hermes Studio visual Workflow canvas.
