ELI10 — The Whole Thing in One Paragraph

There are three layers. Layer 1 is vibe-coding: VS Code + Copilot, prompts, inline edits. Hermes Agent is Layer 2: the runtime, memory, and agent brain that persists across sessions, can run in the background, and talks to messaging platforms. Hermes Workspace is Layer 3: the browser control plane for chat, tasks, operations, swarm, files, terminal, and orchestration. The Dashboard is a part of the operational layer, not the whole product.

ℹ️Product language for this guide: Hermes Agent = runtime + memory + agent brain. Hermes Workspace = browser control plane and orchestration UI. Dashboard = operational console, not the whole product.

Safe-to-try path for vibe coders:
  • Safe to explore first: chat, workspace browse, memory, skills, jobs, tasks, files, terminal.
  • Wait until setup is verified: Conductor, Swarm, Operations, MCP, messaging gateway, and any agent orchestration flow.
  • Common failures: gateway not running, dashboard unavailable, local ports not reachable, or “portable mode” instead of full backend mode.
