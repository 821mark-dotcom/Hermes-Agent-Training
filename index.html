ELI10 — The Whole Thing in One Paragraph

There are three layers. Layer 1 is vibe-coding: VS Code + Copilot, prompts, inline edits. Layer 2 is Hermes Agent: an autonomous agent with persistent memory, 2,000+ skills, and access from Telegram or Slack. It does not include the Kanban board. Layer 3 is Hermes Workspace: the browser-based command center with mission control, Kanban, jobs, swarm, and a live multi-agent dashboard. Each layer works independently. Each makes the layer below more powerful.
