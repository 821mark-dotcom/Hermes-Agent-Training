Hermes Studio Chat — Multi-Agent Walkthrough

⏱ 10 minBeginner
ELI10

You give Hermes Studio Chat one goal. The conductor profile breaks it into smaller jobs, sends those jobs to child agents, watches them finish, and reports what happened. The proof is in the activity events and child results, not in the decorative Workflow canvas.

Verified path: Hermes Studio Chat → conductor profile → native delegate_task → child agents → final report.

1. Start the orchestrator

  1. Open Hermes Studio at http://localhost:8648.
  2. Choose New Chat.
  3. Select profile conductor.
  4. Confirm the provider and model are populated. The tested route shows github-copilot-gpt-4.1 and gpt-4.1.
Checkpoint

If Provider or Model is empty, stop and fix configuration before testing orchestration.

2. Give it a test goal

Paste into chat
You are the orchestrator. Delegate exactly two child tasks in parallel:
Child A: compute 2+2.
Child B: compute 3*3.
Report each child ID, task, and result.

For a real project, replace the arithmetic with a goal that has independent research, implementation, and review work.

3. Watch the delegation evidence

During the run, look for:

  • A tool event named delegate_task.
  • Two child activities or child-result entries.
  • Progress such as 1/2 and 2/2.
  • A completed status for each child.
What success looks like
delegate_task 1/2 · ALPHA Completed
delegate_task 2/2 · BETA Completed

4. Review the final proof

The orchestrator’s final response should contain:

  • Each child agent ID, for example sa-0-....
  • The child’s task and result.
  • A statement that both children completed.
  • A synthesized answer or next action for the parent goal.
Audit trail: Keep the chat session. Its prompt, tool events, child IDs, statuses, and final response are the audit record. Use session history to reopen it later.

5. Real-goal acceptance test

Use this only after the tiny test passes:

Example goal
Research three approaches for this project, have one child draft an implementation plan,
have another challenge the plan, then synthesize a recommendation. Ask me only the
questions needed to resolve genuine ambiguity. Report child IDs, handoffs, blockers,
and evidence before the final recommendation.

What this proves

ObservedMeaning
delegate_task eventThe orchestrator actually delegated work.
Multiple child IDsMore than one agent participated.
Completed child resultsThe work returned to the orchestrator.
Final synthesisThe parent agent managed the result instead of requiring manual relay.
Do not use for proof: the current Studio visual Workflow canvas. It saves graphs, but its runtime can fail before agents start. Chat delegation events are the reliable evidence.
